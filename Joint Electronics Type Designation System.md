A method developed by the [[United States Department of Defense|DoD]] during WW2 for assigning an unclassified designator to electronics equipment.

The core of the JETDS system is the combination of a ==Type Designation== with an ==Item Name== to specify a particular item.
> With the AN/PEQ-2A Infrared Illuminator, the "AN/PEQ-2A" is the Type Designation while the Item Name Code (INC) 26086 "Illuminator, Infrared" is the Item Name.

Items are given an Item Level which describes their hierarchy

# Type Designation (Systems, Subsystems, Centers, Central, Sets)

The ==Type Designation== is a unique series of letters and numbers that describes an item. There are three basic forms of type designators:
- Type designators for definitive Systems, Subsystems, Centers, Central, and Sets (e.g. [[ANSPY-1|AN/SPY-1]]
	- This is made up of a prefix `AN/`, three type desgination indicator letters, a hyphen, and a type designation number.
	- The `AN/` prefix signifies Army-Navy.
	- The three type designation letters specify where the equipment is used, what the equipment is, and what its purpose is.
	- The number helps specify the exact item (we number subsequent same-Installation/Type/Purpose-specified items sequentially)
	- `AN/PRC-77`
		- AN = Army-Navy
		- PRC = Portable Radio used for two-way Communications
		- -77 = The type designation numbers
- Type designators for definitive Groups (e.g. OK-198/G)
- Type designators for definitive Units (e.g. R-1641A/GSQ)
