Uses a data link standard in order to provide communications via radio waves or cable.

NATO nations use a variety of TDL standards. A subset of the more important ones are below:
- [[Link 16]]: The primary NATO/US standard using Time Division Multiple Access (TMDA) for high-capacity, jam-resistant, real-time air-to-air, air-to-ground, and maritime data/voice sharing.
- [[Link 22]]: The modern successor to Link 11, providing secure beyond-line-of-sight maritime, air, and ground data exchanges using high-frequency (HF) and ultra-high frequency (UHF) radio.
- VMF ([[Variable Message Format]]): A digital messaging standard optimized for fast, concise ground maneuvers, targeting, and close-air support communication between digital terminals and forces.
- SADL ([[Situational Awareness Data Link]]): Connects US Army ground forces (like tanks and artillery) directly with close air support aircraft using UHF/VHF bands.
- JREAP ([[Joint Range Extension Applications Protocol]]): Not a standalone radio link, but a protocol allowing TDL messages (link Link 16) to travel long distances over satellite communications (SATCOM) and IP networks.
