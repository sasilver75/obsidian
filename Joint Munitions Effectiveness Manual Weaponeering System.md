See: [[Joint Munitions Effectiveness Manual|JMEM]]

JWS is the primary software package that implements the manuals/data from [[Joint Munitions Effectiveness Manual|JMEM]] into interactive calculations. JWS is the modern digital implementation of the data and methodologies provided by JMEM.

Combines a series of weapon system characteristics, delivery accuracy, and target vulnerability data to estimate the final aimpoint, delivery conditions, and the number of weapons on target necessary to achieve the [[Combatant Commander|CCDR]]'s desired lethal effects.
