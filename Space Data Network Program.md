A [[United States Space Force|Space Force]] initiative designed to connect military and commercial satellites into a secure, multi-orbit mesh network ferrying data from sensors to operational forces globally.

The Space Data Network Backbone (SDN-B) is essentially the new name for the [[MILNET]] concept; the Space Force essentially took the classified architecture briefly known as MILNET (A joint Space Force/[[National Reconnaissance Office|NRO]] concept for a highly secure proliferated LEO data routing network) and fully handed the keys over to [[SpaceX]] to build it using their [[Starshield]] platform.

The Space Force gave SpaceX total design authority, dictating only performance metrics. SpaceX decides how many satellites to launch and where to put them. The constellation forms an interconnected web using laser communication terminals. The "language" of this network is Link-182.
