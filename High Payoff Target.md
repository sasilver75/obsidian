A target that is important to the friendly plan.
A target whose successful engagement helps the friendly commander accomplish the friendly mission.

The key point is that a high-payoff target is good to hit from the friendly plan's perspective.
- An enemy artillery battery that can disrupt tomorrow's river crossing
- An air defense radar that must be suppressed before friendly aircraft enter an area
- A logistics convoy that would prevent the enemy from reinforcing the decisive point
- A command post whose disruption would slow an enemy counterattack

A High-Payoff target is ==usually selected from the broader set of [[High Value Target|High-Value Target]]s==; it's nice if a target can be both important for your plans and important for the adversary's plans.


See also: [[High Value Target|High-Value Target]], [[Time Sensitive Target|Time-Sensitive Target]]


High Payoff Target List: In [[Fires]], a prioritized list of targets critical to the success of a friendly mission, derived from a [[High Value Target]]s (HVT) list.
