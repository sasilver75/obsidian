Communication where both sides can transmit, but not simultaneously.
- Walkie-talkies
- Many radio links

Mental mode:
> Walkie-talkie. Either you talk or the other person talks. If both people talk at the same time, the messages interfere or one side wins.


Mechanically, half-duplex systems often share one communication medium/frequency/collision domain. Because the same resource is used for both directions, the system needs a rule for turn-taking.
- Walkie-talkies use push-to-talk.

Half-Duplex systems often need [[Media Access Control]], which means rules for deciding who may transmit next. Wi-Fi uses contention-based rules, while walkie-talkies use human turn-taking.
