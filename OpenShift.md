From Red Hat


> An enterprise-grade [[Platform as a Service]] built on [[Kubernetes]] container orchestration.

Helps organizations build, deploy, manage, and scale containerized applications across hybrid and multi-cloud environments seamlessly.

OpenShift provides a fully integrated ecosystem out of the box:
- Built-in CI/CD pipelines: Automates software delivery using OpenShift Pipelines powered by cloud-native Tekton building blocks.
- Robust Web UI to monitor health/resource usage/deploy projects.
- OpenShift Virtualization allows orgs to run traditional VMs side-by-side with modern containers.
- Source-to-Image (S2I): Converts raw application code directly into production-ready container images automatically.
- Enterprise Security: Implements strict default security configurations and strict identity access controls to mitigate external exposures.
