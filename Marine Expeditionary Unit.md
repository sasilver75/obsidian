The smallest routinely-deployed [[Marine Air-Ground Task Force|MAGTF]]: a self-contained, forward-deployed Marine force built to respond quickly to crises from sea.
Has its own command element, ground combat force, aviation force, and logistics force.

Commonly ~2,000-2,400 Marines and sailors, though exact size depends on mission/depoyment configuration.

A MEU usually has four parts:
1. Command Element (MEU headquarters)
2. Ground Combat Element (Battalion Landing Team)
3. Aviation Combat Element (Composite Aviation Squadron)
4. Logistics Combat Element (Combat Logistics Battalion Detachment)

A MEU usually deploys *aboard* a [[United States Navy|Navy]] [[Amphibious Readiness Group]] (ARG), which commonly includes amphibious ships like:
- An amphibious assault ship
- An amphibious transport dock
- A dock landing ship, depending on availability and force structure

Together, the package is often called an ARG/MEU.

Some MEUs are described as "special operations capable" in the sense that they've trained for certain specialized missions, but it's still a conventional Marine Corps formation, not under MARSOC.
