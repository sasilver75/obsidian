Status Code System:
- Code 0: Ground Abort: The aircraft experienced a severe issue before takeoff, forcing the pilot to cancel the mission.
- Code 1: Mission Capable/Perfect: No additional discrepancies were found during the flight.
- Code 2: Minor Discrepancies: The aircraft has faults, but it is still capable of being turned around quickly for its next scheduled mission.
- Code 3: Major Discrepancies: Severe faults in mission-essential equipment that require extensive maintenance or part replacements before the aircraft can fly again.
- Code 4: Contamination: The aircraft of its system have suspected or known radiological, chemical, or biological contamination.  
- Code 5: Battle Damage: The aircraft has sustained apparent or suspected damage from hostile engagement.


The most common phrases heard on the flight line is Code 1, 2, and 3.
