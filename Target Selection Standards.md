Criteria used to evaluate enemy activity and decide if a reported object is an actionable target or a suspected indicator.

They use four main elements:
1. ==[[Target Location Error]] (TLE)==: 
2. ==Size==: Minimum number of target elements required for targeting or worth engaging. May also vary by weapon system.
3. ==Activity Status== (Describes the status of the enemy activity (e.g. stationary, moving) based on the target's expected dwell time or on station time.)
4. ==Timeliness== (Last time)
