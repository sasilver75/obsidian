---
aliases:
  - IATT
  - Interim Authority to Test
---
A ***temporary*** (expires after set timeframe) approval granted to evaluate an information system in a specified operational environment. Meant for active evaluation, security control checks, and system diagnostics rather than general production use. Applies to a specific environment under constraints set by an Authorizing Official.

Allows system teams to run tests, connect to networks, and gather security data under strict time limits and rules before receiving full [[Authorization to Operate]] (ATO).
