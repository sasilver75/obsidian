The foundational intelligence and planning process used to systematically examine an adversary's capabilities, requirements, and vulnerabilities.

The process of analyzing an adversary capability as a connected system so that planners can understand which parts matter, how the parts interact, and what effects might change the adversary's behavior or capability.

> “What function does this enemy system perform, what components make that function work, and which components are most important to affect?”

==Don't think of the target system as an object; think of it as a machine made of people, equipment, facilities, communications, logistics, procedures, terrain, and timing==

> You can destroy an enemy fighter while it's in its hangar, or you can look at the fighter as a system, and ask "Where does the pilot sleep?", "What sort of fuel does it use?", "What's the supply chain for the tires that the airplane uses to land and take off?" If you can disrupt the specialized rubber production for the tires, which might be halfway across the world, you don't even have to kinetically action the plane itself to keep it out of the fight. Attacking a single fighter might not even matter if the system has redundancy (more fighters), or can recover (manufacture more fighters) quickly.

TSA helps answer:
- What enemy function matters?
- What system performs that function?
- What components make the system work?
- Which components are critical?
- Which components are vulnerable?
- What [[Effect]] would matter? Destroy, disrupt, delay, deceive, suppress, isolate, deny?
- How would we know whether the effect happened?

TSA can produce:
- Target system description
- System diagrams or nodal analysis
- Critical nodes and links
- Candidate [[High Value Target|High-Value Target]]s
- Dependencies and redundancies
- Intelligence collection requirements
- Indicators that a system is active, degraded, or recovering
- Possible desired effects
- Assessment criteria for battle damage assessment or broader operational assessment


> Comparison with [[Weaponeering]]: TSA asks what parts of the adversary system matter, and why, while Weaponeering asks what capability can create the desired effect on a specific target.
