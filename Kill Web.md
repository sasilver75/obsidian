Replaces linear [[Kill Chain]]s (a fixed sequence from finding to destroying a target) with a resilient, cross-domain mesh network.


![[Pasted image 20260714142834.png]]




![[Pasted image 20260715104637.png]]
Above: a traditional [[Kill Chain]], where each have assets allocated to a specific job

![[Pasted image 20260715104657.png]]
Instead, a [[Kill Web]] distributes all steps for all kill chains across all battlespace to all assets in the battlespace, creating sensor/strike redundancy, so if a drone get shots down, the job seamlessly transitions to the next drone.
