https://www.chainguard.dev/

Chainguard provides security-hardened container images designed to minimize vulnerabilities and pass compliance scans.

Their images typically contain only the packages required top run the application, receive frequent security updates, and avoid unnecessary shells or utilities.




> "What we use Chainguard for is base images to build on top of."
> ((I believe we use them for PostgreSQL and BusyBox))
> - RPC
