An [[International Organization for Standardization|ISO]] standard for property graph querying, heavily influenced by [[Neo4j|Cypher]] and the openCypher project.

```
Neo4j Cypher
  = Neo4j's native graph query language

openCypher
  = open specification based on Cypher for other implementers

GQL
  = ISO standard property graph query language, influenced by Cypher and others
```
