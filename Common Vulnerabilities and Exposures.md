A CVE vulnerability is a publicly-known security flaw or weakness is software or hardware.

Each flaw gets a unique ID like `CVE-2026-XXXX` (CVE, year it was founded, and a unique number) so that security teams worldwide can track, name, and fix the same problem using a shared system.


# Relation to CVSS Scores

A CVE gives a security hole a name and trakcing number, while a [[Common Vulnerability Scoring System]] (CVSS) rating gives a 0.0-10.0 severity rating:

| CVSS Score Range | Qualitative Severity Rating |
| ---------------- | --------------------------- |
| 0.0              | None                        |
| 0.1-3.9          | Low                         |
| 4.0-6.9          | Medium                      |
| 7.0-8.9          | High                        |
| 9.0-10.0         | Critical                    |

CVSS scores are based on Base (exploitability, impact), Temporal, and Environmental metric groups.
