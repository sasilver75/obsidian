The overarching [[Department of Defense|DoD]] program and data repository for  conventional weapons effectiveness.

[[Joint Munitions Effectiveness Manual Weaponeering System|JMEM Weaponeering System]] (JWS) is the actual primary software package that integrates those manuals and data into interactive calculations; it's the modern digital implementation of the data and methodologies provided by JMEM.
